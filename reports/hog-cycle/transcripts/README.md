# 参考视频转写稿

本目录存放研究过程中参考的视频字幕，**仅作本地检索与交叉验证用，转写正文不纳入版本控制**（见仓库根目录 `.gitignore`）。

原因有两点：一是完整转写稿是他人作品的逐字复制，公开重发不合适；二是 AI 转写错误率不低，公开会造成误传。研究报告里如需引用，应当注明视频出处与时间点，并用自己的话转述。

- `BV1qhen6GEbi.meta.json` —— 标题、UP 主、时长、播放量、标签等元信息

## 重新生成

字幕轨需要 B 站登录态才能访问，脚本依赖浏览器里已登录的 cookie：

```bash
python3 fetch.py BV1qhen6GEbi
```

依赖 `yt-dlp` 与一个已登录 B 站的 Chromium 系浏览器（脚本默认读 Edge）。B 站的 `player/v2` 接口对字幕轨的返回不稳定，所以脚本走 yt-dlp 而不是直接调 API。

## 使用须知

AI 转写对专有名词、数字、公司名的识别错误率较高——猪价、出栏量、成本这类关键数字尤其不可信。**任何要写进报告的数据都必须回到公司公告或交易所原始来源核对**，转写稿只用来定位"他在哪一段讲了什么"，不作为数据来源。

按仓库的数据可信度分级，视频转写内容属于 C 类（媒体转述），引用时需明确标注。
