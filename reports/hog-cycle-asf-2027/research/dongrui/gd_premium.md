# 广东相对全国猪价价差：历史证据、供需成因与本轮能否重现

核验日：2026-10-09。凡标“推断”者为本文计算或推理，非原始资料陈述；其余数字均附 URL 与逐字摘录（≤200字）。

## 结论先行

- **历史价差属实，但“超过5元”只是个别时段。** 公司2023年审核问询回复（财务数据更新版）原文称2019年7月—2021年4月广东均价“显著高于全国”，“个别时间段，价差超过5元/公斤”。全国均价只以 Wind 图表形式出现，正文没有给出逐月数值。
- **上一轮价差扩大的主因是非瘟冲击，而非常态。** 广东本地产能断崖（2019年出栏−21.8%、能繁−39.9%）、外省活猪占比一度升到约4成，叠加中南区2019-11-30起限制区外活猪调入、2020-11-30起原则上禁止区外生猪调入且区内原则上不跨省（但浙皖豫鄂渝云贵已备案企业仍可“点对点”供粤）；广东2021-08-15起暂停非中南区“点对点”屠宰生猪，2022-05-01起暂停全部省外屠宰生猪（无疫区、无疫小区除外）。（更正：原文只写到2020-11-30，同源价差与政策核验见 Issue #4 答复 issues/04-guangdong-premium.md。）
- **本轮价差明显收窄。** 用新牧网“华南-全国”周度价差作代理：2019-07～2021-04均值2.27元（峰值6.26元），2023年至2026年迄今均值仅0.68—0.75元，2026年下半年约1.0元。代理只能近似广东，华南≠广东。公司内销价相对全国均价近两年约+0.3元（推断）。
- **反面证据更强（推断）。** 广东产能处于高位：2025年出栏4024.96万头、2026上半年出栏同比+8.4%（全国+1.7%）；二季度末能繁206.51万头，约为广东方案正常保有量189万头的109%，已高于方案红色区域阈值106%。另外，猪肉产品调入广东不受限。要重现“>5元”，需要再出现本地产能断崖叠加跨区调运受限，目前看不到这些条件。
- **供港溢价同样大幅收窄。** 出口与内销价差从2019—2021年的约9—12元/公斤降到2025年的1.82元、2026Q1的1.74元、2026H1的1.10元。

## 二、上一轮价差扩大的供需原因

### 1. 广东长期自给不足、依赖外省调入
- 21世纪经济报道2019-12-11（援引广东省农业农村厅）：“根据广东省农业农村厅的数据，广东常年生猪出栏量约3700万头，自给率65%左右，每年需调入生猪约1000多万头。” 同文：“根据2018年的数据，广东省肉猪出栏头数达到3757.4万头，自给率65%左右。” https://m.21jingji.com/article/20191211/herald/950356eff9cfd14ad549d63790654d67.html
- 公司申报文件引《广东省现代畜牧业发展“十四五”规划（2021-2025年）》：“到2025 年，广东省生猪出栏量达到3,300 万头以上，自给率保持在70%以上，据此测算，广东省生猪消费需求缺口约为1,400 万头，需要从外省调入生猪或猪肉。”（缺口为公司测算）https://static.cninfo.com.cn/finalpage/2023-05-22/1216871308.PDF

### 2. 非瘟导致本地产能断崖、外省活猪占比骤升（二手转述，口径为省内监测）
- 汇易网《2019年广东省生猪产销形势分析》：“出栏总量降至2940.2万头，为近五年最低水平，较2018年减少817.2万头，同比下降21.8%”；“其中能繁母猪存栏量降至131.0万头，较上年末下降87万头，同比下降39.9%”。https://www.chinajci.com/article/a2102023R.html
- 同文：“上半年我省受非洲猪瘟限制调运影响，外省调入生猪数量在15%以内，但自6月开始，省外活猪供给占比明显增多，据兽医与屠宰管理处数据，6月外省活猪供给已占近三成，7-11月持续占比约为4成，12月虽受禁调影响，仍占3成以上。”
- 同文：“全年生猪出栏均价为22.8元/公斤，同比上涨65.6%……下半年受供给减少影响，猪价快速上涨至31.7元/公斤”。（该文为第三方网站转载，未找到省农业农村厅原始页面，属二手来源）
- 羊城晚报2020-02-04（援引省农业农村厅）：“2019年12月底全省生猪、能繁母猪存栏分别为1092.49万头、124.32万头，同比分别下降46.0%、44 ... 0%”（原页面数字有截断）https://ycpai.ycwb.com/ycppad/content/2020-02/04/content_635916.html

### 3. 跨省调运限制与指定通道
- 中南区试点：21财经同文：“广东、福建、江西、湖南、广西和海南六省区自2019年11月30日起，开始试点禁止非中南区的活猪调入中南区（种猪、仔猪除外；在2020年11月30日前，符合中南区跨大区‘点对点’调运备案要求的生猪除外）……自2020年11月30日起，中南区内省区与省区之间禁止活猪（种猪、仔猪除外）跨省区调运。”
- 广东省农业农村厅《中南区2020年版生猪调运政策解读》（2020-11-27）：“根据《关于印发〈中南区生猪调运管理办法〉和〈中南区区域外动物及动物产品进入中南区指定通道名单〉的通知》（中南区联防〔2020〕1号）文件要求，自2020年11月30日起，全面禁止非中南区的生猪（种猪、仔猪除外）调入中南区”；“‘点对点’调运的直线距离，原则上不超过1000公里。”；“这次发布的128个指定通道，是从方便群众的角度考虑，将中南6省（区）指定通道信息整合一并发布。” https://dara.gd.gov.cn/zwgk/zcjd/content/post_3137338.html
- 广东省防控重大动物疫病应急指挥部《关于进一步加强生猪及生猪产品调运管理的通知》（粤动防指〔2022〕1号，2022-04-12）：“一、自2022年5月1日起，暂停省外屠宰用生猪调入我省。”；“二、获得国家非洲猪瘟无疫区、无疫小区评估认定的省外生猪养殖企业，办理生猪‘点对点’调运备案后，可‘点对点’调运屠宰用生猪到我省。”；第四条：“省外经检疫和肉品品质检验合格的生猪产品，可依法调入我省，无须备案，无须经过指定通道。” https://dara.gd.gov.cn/zwgk/tzgg/content/post_3911258.html
- 该制度仍在运行（推断依据）：广东省农业农村厅公告2025年第10号（2025-02-22）公布“非洲猪瘟无疫小区生猪‘点对点’供粤备案企业名单（第十七批）”。https://dara.gd.gov.cn/zwgk/tzgg/content/post_4674023.html 。2026年是否调整未检索到，**缺失**。
- 公司对2022年禁调的评价（2022-04-29交流记录）：“这一政策的发布，对广东地区的养殖企业而言，有一定的信心提振，对广东猪价和防疫有明显利好。外省供港生猪和广东省活猪禁运是不冲突的”。https://static.cninfo.com.cn/finalpage/2022-04-29/1213261824.PDF

### 4. 省政府稳产保供文件
- 《广东省人民政府办公厅关于加快推进生猪家禽产业转型升级的意见》（粤府办〔2019〕25号，成文2019-12-24）：“到2025年……生猪出栏量保持在3300万头以上、自给率保持在70%以上”；“将最低生猪出栏量纳入‘菜篮子’市长负责制考核”。http://www.gd.gov.cn/zwgk/wjk/qbwj/yfb/content/post_2794276.html
- 广东省农业农村厅《关于印发我省促进生猪生产保障市场供应十条措施的通知》：“实行生猪生产红线制度，各地级以上市生猪出栏量不得低于《广东省生猪生产发展总体规划和区域布局（2018—2020年）》（粤农农〔2019〕185号）规定的目标任务”。https://dara.gd.gov.cn/zwgk/tzgg/content/post_2571885.html
- 全国层面：《农业农村部关于稳定生猪生产保障市场供给的意见》（农牧发〔2019〕9号）：“生猪自给率低的销区要根据当地情况，积极扩大生猪生产，合理规划布局，逐步提高生猪自给率。” https://www.gov.cn/zhengce/zhengceku/2019-10/28/content_5445996.htm

**机制小结（推断）**：价差＝本地缺口 × 外部补给受阻程度。2019年下半年到2020年，本地产能骤降叠加区外活猪禁入/限入，外部补给只能靠“点对点”通道和冷冻肉，价差因此放大到5元以上。2021年5月以后全国产能恢复，价差回到1元左右；2022年5月的省外屠宰猪禁调只把价差短暂推高（新牧网2022-05-23华南-全国2.27元），没有再现2020年的水平。

## 四、本轮能否重现：正反证据

### 支持价差再扩大的证据
1. **主销区地位与“调猪向运肉”导向未变。** 广东方案原文：“我省为生猪主销区省份，生猪自给率要保持70%以上，随着‘调猪向运肉’转型升级不断推进，生猪跨省调运将逐步减少，猪肉供应面临较大考验”。https://www.gd.gov.cn/gdywdt/zwzt/bxqzwc/zxzc/content/post_4950590.html 。（推断）活猪跨省套利的通道窄，全国供给收紧时广东活猪价可能弹性更大。
2. **省外屠宰用生猪入粤仍须“点对点”备案（推断仍有效）**，同上第二节第3点。
3. **2026年下半年价差有所回升。** 新牧网华南−全国2026H2均值1.03元，10月8日快照约1.37元（推断）。
4. **全国能繁同比下降。** 国家统计局：二季度末能繁3780万头，同比下降6.5%，为正常保有量3750万头的100.8%。https://www.stats.gov.cn/sj/sjjd/202607/t20260716_1964140.html 。（推断）如果全国在2027年进入上行，主销区的弹性通常更大，但这只是方向判断。

### 反对价差大幅扩大的证据（目前更强）
1. **广东本地产能处于高位、增速快于全国。**
   - 2025年：“2025年生猪出栏4024.96万头，同比增长5.4%。”（https://gdzd.stats.gov.cn/sjfb/sjjd/202601/t20260120_182632.html ），已超过“十四五”3300万头目标。
   - 2026H1：“2026年上半年，广东生猪出栏2203.18万头，同比增长8.4%。”（国家统计局广东调查总队2026-07-17）；同期全国出栏同比+1.7%（国家统计局）。
   - 二季度末广东能繁206.51万头，同比−0.8%，降幅远小于全国的−6.5%。
2. **按广东省方案自己的口径，广东能繁偏高（推断）。** 方案规定“全省能繁母猪正常保有量稳定在189万头左右”，并规定“各地级以上市季度末月份能繁母猪存栏量为国家统计局广东调查总队数据”。206.51÷189≈109.3%，高于方案红色区域阈值106%。红色区域措施原文：“督促指导全行业继续加大低产母猪淘汰力度，暂缓补栏能繁母猪和新建扩建猪场。”目前未检索到官方宣布广东进入红色区域。它的含义是：广东本地供给充足，同时省级调控方向是**压产**而非鼓励扩产。
3. **猪肉产品调入不受限。** 粤动防指〔2022〕1号第四条（见上），白条/冷鲜肉可补缺口，会把活猪价差限制在一定范围。
4. **上一轮的条件是一次性冲击。** 2019—2020年的价差来自非瘟导致的区域性断供、全国产能大幅低于正常水平和区外活猪禁入三者叠加。当前全国产能处于绿色区间（100.8%），广东产能偏高，三项条件都不具备。
5. **公司自身数据显示溢价收窄。** 公司内销价相对全国约+0.3元（推断）；供港溢价从约9—12元降到1.1—1.8元；2025年投资者已在问“价格优势逐渐减弱”。

### 研判（推断，不是预测）
- 常态下，广东相对全国的溢价大致落在0.5—1.5元/公斤区间：新牧网华南代理2023—2026年均值0.7元左右，广东单省应略高；公司2024年口径为“1元左右”；2026-10-08快照约1.4元。
- 要重现“>5元”，需要广东本地产能出现断崖（疫病或环保），同时跨区活猪和猪肉补给受阻。在2026年广东产能偏高、省方案倾向压产的背景下，这一情景概率低。
- 对东瑞的含义（推断）：2027年做利润模型时，“公司内销相对全国溢价”取0.3—1.0元更稳妥；出口溢价用最近的1.1—1.8元，并按出口重量占比约19%—29%（2026Q1与2025年的推算值）折算进综合价，不应按全部出栏加成。由此估算，公司综合价相对全国约高0.5—1.0元/公斤（推断）。
