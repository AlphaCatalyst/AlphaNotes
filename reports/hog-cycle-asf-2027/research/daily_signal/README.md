## 重跑

在专题目录 `reports/hog-cycle-asf-2027/` 下：

```bash
python3 scripts/fetch_csi_index.py 20261030     # 中证畜牧养殖、中证全指日收盘
python3 scripts/issues/daily_signal.py fetch   # 抓取钢联列表与文章、中国养猪网省级表和河南页面、两家龙头日线；首次运行要下载约 800 个页面
python3 scripts/issues/daily_signal.py         # 生成 data/processed/issues/ds_*.csv 和 4 张图
```

第二步还需要本地的新牧网和期货序列（`scripts/industry/nxin_prices.py`、`scripts/fetch_futures.py`），以及 Issue #6 的 `ad_supply_schedule.csv`。钢联列表每个栏目只能翻 10 页，更早的出栏表无法补抓；已抓到的文章会缓存在 `_raw/mysteel/`，重跑时不再下载。
