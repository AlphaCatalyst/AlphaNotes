## 抓取方法

匿名访问雪球公开页面，不登录。用到的渠道：

- **用户时间线：** “全部”“原创”“长文”“热门”四个类型各取第一页，每页约 20 条。第二页以后和按时间筛选都需要登录，没有使用。
- **专栏列表：** 可以匿名翻页。一凡翻到第 5 页，回溯到 2026-03-19；春风翻 2 页，回溯到 01-30；我不帅你报警第 1 页已回溯到 02-24。所以这三人窗口内的专栏是完整的。豆区没有专栏和长文。
- **用户内关键词搜索：** 每个词返回该作者最近 10 条匹配的帖子，共 41 个词：生猪、猪价、母猪、能繁、仔猪、出栏、体重、二育、冻品、产能、去化、调控、政策、收储、反内卷、周期、拐点、底部、预期差、期货、成本、利润、亏损、估值、市值、消费、疫，以及牧原、温氏、新希望、神农、巨星、德康、东瑞、天康、唐人神、天邦、京基、华统、立华、新五丰。
- **转发链：** 作者转发或回复时会附带被转发的帖子。如果被转发的是作者本人在窗口内的帖子、而其他渠道没有抓到，就单独记为“原帖（经转发获取）”。
- **全文：** 列表只给摘要的长帖，通过帖子页补全。

## 覆盖缺口

**没有检索到的帖子，不等于作者没有讨论过。**

- **我不帅你报警：** 专栏和长文完整。时间线第一页只回溯到 08-17，之前的普通帖和评论区回复只能靠关键词搜索和“热门”找到。
- **一凡帝诺维奇：** 专栏完整，普通帖很少。评论区回复只收录了以转发形式出现的。
- **_春风_：** 主页共 101 帖，找到 80 条，最早到 2026-01-16。窗口内找到的第一帖是 05-05，4—5 月是否还有别的帖子无法确认。5 条只有摘要，都与猪无关。
- **豆区：** 主页共 322 帖，找到 131 条，全部晚于 08-07（关键词搜索最早到 08-07，时间线第一页最早到 08-09）。08-07 之前即使有帖子也没有找到。作者 06-08 在视频平台的动态以截图形式转贴在雪球，只作背景材料。
- **共同的限制：**
  - 配图大多没有下载或识别，底稿中据图概括的内容已注明；
  - 帖子可能在抓取后被编辑或删除，`edited` 列只记录抓取时已有的编辑时间；
  - 作者在别的平台（直播、视频）的观点没有系统收集。

## 分类规则

`articles.csv` 的 `kind` 列：

| 值 | 含义 |
| --- | --- |
| 专栏 | 出现在作者专栏列表中的文章 |
| 长文 | 雪球“长文”类型，但不在专栏列表中 |
| 带图帖 | 附图的普通帖 |
| 普通帖 | 不附图的短帖 |
| 转发或评论 | 雪球把转发和评论区回复都记为“转发”；只算作者本人写的文字 |
| 原帖（经转发获取） | 作者本人的帖子，只能通过转发链拿到 |

答复正文在此基础上再按内容分开：

- **作者原创：** 作者本人的专栏、长文和帖子。
- **评论区补充：** 作者在评论区或转发时写的文字。被回复者的观点不计入作者观点，底稿中引用时标“评论者原话”。
- **转载：** 转发他人文章且没有加评论，例如一凡 04-21 转载《助农模范损失超百亿》；声明不代表本人观点的转述（一凡 06-25 转述牧原 AI 的猪价预测）也不计入。
- **公司信息整理：** 一凡整理牧原官方信息的 6 篇专栏，公司表态不等于作者观点。
- **背景材料：** 作者引用的窗口外文章，例如我不帅你报警 2025-05-19《2025Q1猪企状况全家福》、一凡的产能调控政策体系系列、春风《天邦食品分析报告（2026-04-17）》。

另外两列标记：

- `hog`：标题、正文或被转发内容含猪相关关键词（正则见生成脚本）记为 1。
- `core`：底稿第 1 节文章索引中标 ★ 的核心长文，共 74 篇。

## 公开范围

- 帖子全文、配图和抓取缓存只保留在本地，不公开。
- 公开的只有：索引（不含正文）、底稿中的摘要、不超过 40 字的逐字短引文、帖子 id 和链接。
- 评论区其他用户的昵称已隐去：索引中替换为“其他用户”“@用户”“某用户”，底稿中写作“评论者”或“评论者甲、乙”。
- 作者自述的身份、持仓和交流会见闻均未经核实。

## 重跑

在专题目录 `reports/hog-cycle-asf-2027/` 下：

```bash
python3 scripts/issues/xueqiu_index.py    # 需要本地 _raw/xq_db.json；核心长文标记读自 notes/
python3 scripts/issues/xueqiu_checks.py   # 生成 data/processed/issues/xueqiu_*.csv；需要本地的新牧网和期货原始序列
```

观点还原由子研究按统一提纲逐篇阅读完成，研究者通读全部底稿，并对答复中用到的关键数字和引文逐项核验。底稿中没有被答复引用的细节，以底稿自己的标注为准。
